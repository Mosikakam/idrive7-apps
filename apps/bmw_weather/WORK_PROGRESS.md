# BMW Weather Widget — состояние проекта

Дата фиксации: 10 ноября 2026 года.

## Краткий статус

Подготовлен исходный код пользовательского погодного приложения для MGU / iDrive 7. В проекте есть экран прогноза, анимированный домашний виджет `startWidget`, клиент Open-Meteo, манифест приложения и инструкция на русском. Приложение ещё не собрано в устанавливаемый пакет и не устанавливалось на автомобиль.

## Реализовано

- Получение текущих погодных условий и прогноза на пять дней через HTTPS-запрос к Open-Meteo.
- Отображение температуры, ощущения, влажности, ветра, погодного описания, дневного максимума/минимума и вероятности осадков.
- Рисование анимированных солнца, облаков, дождя и снега средствами canvas из MGU app kit.
- Экран приложения с кнопкой обновления и домашний виджет, который обновляется с умеренной частотой анимации.
- Период обновления по умолчанию — 30 минут; доступны 15 и 60 минут.
- Переключение °C/°F.
- Задана приблизительная точка центра Петропавловска-Камчатского (`53.017, 158.650`). Это координаты города, не машины или дома. Приложение отправляет их погодному API при запросах.
- Добавлена атрибуция Open-Meteo в интерфейсе.

Приложение не вызывает BMW Online/ConnectedDrive API и не пытается перенаправлять штатный трафик BMW.

## Технологии и API

- JavaScript в стиле Node.js 8, принятом приложениями MGU.
- MGU custom app kit: `require('./kit/mgu')`, `mgu.run`, `ctx.loop`, `ctx.canvas`, `ctx.ui.image`, настройки и `ctx.widget.loop`.
- RHMI home widget (`startWidget`) на шаблоне `LT_Table_OnlineApps_DriveRecorderWidget` с ячейкой `BackgroundImage1`.
- HTTPS API: `https://api.open-meteo.com/v1/forecast`, параметры `current`, `daily`, `forecast_days=5`, `timezone=auto`.
- Internet Uplink MGU Store заявлен через `mguInternet: true`; реальный сетевой доступ приложения на машине ещё нужно проверить.

## Сборка и установка на BMW MGU High

ZIP содержит именно исходники погодного приложения, а не весь репозиторий iDrive7 apps и не готовый `.mgu`.

### Вариант через MGU Store

1. В форке `Mosikakam/idrive7-apps` добавить приложение как `apps/bmw_weather/`: `app.json`, `main.js`, `weather.js` и подходящие метаданные MGU Store.
2. Сначала работать в отдельной ветке `feature/bmw-weather-widget`; не коммитить прямо в `main`.
3. В Store добавить свой форк как источник и установить Weather. Store должен собрать исходники для ID7 с SDK, доступным на головном устройстве.
4. Убедиться, что Internet Uplink показывает `Online`, затем открыть Weather и проверить обновление.
5. В выборе виджетов домашнего экрана добавить Weather.

### Вариант локальной сборки комплектом

В клоне/форке `idrive7-apps` приложение должно находиться в `apps/bmw_weather/`; сборка в комплекте запускается командой вида `python kit/tools/build.py bmw_weather`. Для полного `.mgu` требуется SDK BMW (`oap-sdk`) с вашего головного устройства. Этот SDK намеренно не содержится в проектном архиве. Установку из файла следует выполнять только после подтверждения совместимости и проверки результата сборки.

Текущий исходный код не проверялся в настоящем комплекте сборки; команды выше следуют опубликованной структуре iDrive7 apps и требуют практической проверки после интеграции.

## Нерешённые проблемы и ограничения

- Совместимость именно с BMW X3 G01 / MGU High / прошивкой `P18_23w44.2-1-3` не подтверждена запуском на автомобиле.
- Шаблон `LT_Table_OnlineApps_DriveRecorderWidget` и ячейка `BackgroundImage1` выбраны по документации и аналогичному примеру; их работа и кадрирование на этом G01 не проверены.
- Не проверено, предоставляет ли конкретный билд MGU Store приложению доступ к внешнему HTTPS через Internet Uplink с текущим сертификатным хранилищем устройства.
- Не проверено, что текущая структура `package.json` корректно передаёт `mguInternet: true` в установленный пакет.
- Координаты статичные, автоматического получения GPS автомобиля нет.
- Open-Meteo бесплатный API предназначен для личного некоммерческого использования; требуется атрибуция и применяются условия провайдера.
- Прогноз и иконки не были проверены визуально в BMW UI, поэтому возможна необходимость изменения размеров, crop и размеров шрифтов.
- Готового устанавливаемого `.mgu`/`.tgz` в архиве нет: необходим сборочный комплект и SDK с автомобиля.

## Продолжение разработки — 10 ноября 2026 года

Репозиторий `Mosikakam/idrive7-apps` доступен на чтение и запись. Создана ветка `feature/bmw-weather-widget` от `main`; код из архива перенесён в `apps/bmw_weather/`. Пять файлов из второго архива побайтно совпадают с соответствующими файлами первого.

При интеграции выявлены и исправлены две ошибки исходного кода: `ctx.canvas()` возвращает экранный Recorder, который нельзя передавать `ctx.widget.loop()` вместо пиксельного Canvas; а аргументы `cv.line()` были в неверном порядке. Виджет теперь рисует через `ScaledCanvas` и возвращает его пиксельный Canvas. Содержимое виджета помещено в безопасную область кадрирования.

Добавлен `icon.png` для каталога MGU Store и плитки приложения; погодные рисунки внутри виджета по-прежнему создаются кодом.

Сборщик `kit/tools/build.py` берёт данные приложения из `app.json`, а исходный `package.json` не читает. Поэтому `mguInternet: true` добавлен в `app.json`, и сборщик переносит его в итоговый `source/package.json`. `mgu-repo.json` уже объявляет путь `apps/*`, совместимость `ID7`, сборщик, его выходной `.tgz` и папку для `oap-sdk`; отдельная запись приложения не нужна. Поле `network` в каталоге относится к сетевому доступу во время сборки, а приложение в ходе сборки ничего не скачивает.

Локально пройдены проверка синтаксиса `main.js`/`weather.js`, проверка парсинга JSON и тест запроса, отрисовки обеих поверхностей и сохранения последнего ответа при сетевой ошибке. В CI добавлены запуск `build.py --preview-only bmw_weather` и проверка флага `mguInternet` в сгенерированном пакете. Полноценная сборка `.tgz`/`.mgu` и проверка на автомобиле ещё требуют штатного SDK с MGU; эту часть должен выполнить MGU Store на автомобиле. Совместимость именно с `P18_23w44.2-1-3` и доступность Open-Meteo через Internet Uplink пока не подтверждены на устройстве.

PR: `https://github.com/Mosikakam/idrive7-apps/pull/1`. В форке после открытия PR GitHub Actions не создал запусков; CI-проверка в нём пока не выполнена. В текущем локальном окружении Python отсутствует, поэтому `build.py --preview-only` здесь также не запускался. Код теста отрисовки выполнен локально с реальным модулем Canvas и макетом ответа Open-Meteo.
