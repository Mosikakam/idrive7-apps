# Погода для BMW MGU и iDrive 7

«Погода» — приложение и домашний виджет для BMW MGU. Версия 1.0.9 получает погоду через HTTPS API `wttr.is` (`format=j2`). Интерфейс и домашняя плитка на русском языке.

## Возможности

- Текущая температура, ощущаемая температура, влажность, ветер и описание погоды.
- До трёх дней прогноза с дневными максимумами и минимумами. Компактный ответ `j2` не содержит почасовые данные; для будущих дней значки и вероятность осадков могут отсутствовать.
- Домашняя плитка на чёрном фоне с большим анимированным значком слева и текущей температурой, погодой и диапазоном на сегодня справа.
- Обновление каждые 30 минут по умолчанию, кнопка «Обновить» и выбор °C/°F.
- Последний успешный прогноз остаётся видимым при временной ошибке сети в текущем сеансе.

Источник данных: [wttr.in JSON API](https://github.com/chubin/wttr.in#json-output) через его альтернативный домен `wttr.is`. Координаты передаются этому сервису при каждом запросе.

## Место прогноза

В коде заданы примерные координаты центра Петропавловска-Камчатского: `53.017, 158.650`. Они не берутся из GPS автомобиля. Для другого места измените `LOCATION_LATITUDE` и `LOCATION_LONGITUDE` в `weather.js` и заново соберите приложение.

## Установка и обновление

В MGU Store используйте источник `Mosikakam/idrive7-apps` с веткой `main`. Проверьте обновления в настройках магазина, затем установите или обновите «Погоду». Store соберёт пакет непосредственно на MGU с установленным там BMW SDK. Пакет запрашивает доступ в интернет через `mguInternet: true`.

После установки добавьте «Погоду» в список виджетов главного экрана и проверьте Internet Uplink в Store. Если после обновления осталась прежняя плитка, удалите её с главного экрана и добавьте заново.

Если плитка сообщает, что погода недоступна, откройте приложение, чтобы увидеть причину. Сообщение «Приложение не получило интернет-подключение» означает, что Store ещё не предоставил данные подключения. При тайм-ауте приложение показывает этап, на котором остановился запрос.

В 1.0.9 малая и большая плитки получают PNG через отдельные ячейки `BackgroundImage_Small` и `BackgroundImage_Big` шаблона BMW `LT_Table_BasicWidget`. Поддержку шаблона и кадрирование на прошивке `P18_23w44.2-1-3` нужно проверить в автомобиле. MGU Store собирает устанавливаемый пакет с локальным `oap-sdk`.

## Структура

- `app.json` — экран, настройки, виджет и разрешение на интернет.
- `main.js` — запуск экрана и домашнего виджета.
- `weather.js` — запрос к `wttr.is`, логика прогноза и Canvas-графика.
- `wttr.js` — преобразование компактного ответа JSON.
- `uplink.js` — DNS через собственный файл Internet Uplink приложения.
- `package.json` — метаданные исходного проекта; при сборке пакетный файл создаёт `kit/tools/build.py`.

[Документация iDrive7 apps](https://github.com/cauliflowermossgrape/idrive7-apps) описывает виджеты и сборку. [MGU Store](https://github.com/robertnisipeanu/mgu-store) описывает установку исходников и Internet Uplink.
