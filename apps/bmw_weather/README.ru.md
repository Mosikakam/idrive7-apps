# BMW Weather для MGU / iDrive 7

Weather — приложение и домашний виджет для BMW MGU. Версия 1.0.8 получает погоду только через HTTPS API `wttr.is` (`format=j2`). Запросов к Open-Meteo и диагностических запросов к GitHub больше нет. Штатные BMW Online и ConnectedDrive не используются и не изменяются.

## Возможности

- Текущая температура, ощущаемая температура, влажность, ветер и описание погоды.
- До трёх дней прогноза с дневными максимумами и минимумами. Компактный ответ `j2` не содержит почасовые данные; для будущих дней значки и вероятность осадков могут отсутствовать.
- Экран приложения и домашний виджет `startWidget` с анимированной графикой.
- Обновление каждые 30 минут по умолчанию, ручная кнопка Refresh и выбор °C/°F.
- Последний успешный прогноз остаётся видимым при временной ошибке сети в текущем сеансе.

Источник данных: [wttr.in JSON API](https://github.com/chubin/wttr.in#json-output) через его альтернативный домен `wttr.is`. Координаты передаются этому сервису при каждом запросе.

## Место прогноза

В коде заданы примерные координаты центра Петропавловска-Камчатского: `53.017, 158.650`. Они не берутся из GPS автомобиля. Для другого места измените `LOCATION_LATITUDE` и `LOCATION_LONGITUDE` в `weather.js` и заново соберите приложение.

## Установка и обновление

В MGU Store используйте источник `Mosikakam/idrive7-apps` с веткой `main`. Его каталог содержит только Weather. В Settings выберите Check now, затем установите или обновите Weather. Store соберёт пакет непосредственно на MGU с установленным там BMW SDK. Для доступа в интернет `app.json` объявляет `mguInternet: true`; сборщик переносит этот флаг в пакет.

После установки добавьте Weather в список виджетов главного экрана и проверьте Internet Uplink в Store. Если после обновления остаётся прежняя версия или ошибка, удалите Weather через Store и установите заново, затем снова добавьте плитку.

При `Weather unavailable` откройте приложение и прочитайте строку под заголовком. `No Internet Uplink lease for Weather` означает отсутствие файла подключения приложения. `TCP timeout` означает, что соединение с `wttr.is:443` не установилось за отведённое время. `response body 0B` означает, что ответ не передал данные до тайм-аута. Состояние Online самого Store ещё не доказывает доступность конкретного погодного адреса.

Проверены синтаксис JavaScript, манифесты, сетевые сценарии с макетами ответов, отрисовка и запуск только домашнего виджета. Реальный HTTPS-ответ и изображение виджета нужно проверить в автомобиле. Полный пакет `.tgz` здесь не собирался: штатный `oap-sdk` находится на MGU.

## Структура

- `app.json` — экран, настройки, виджет и разрешение на интернет.
- `main.js` — запуск экрана и домашнего виджета.
- `weather.js` — запрос к `wttr.is`, логика прогноза и Canvas-графика.
- `wttr.js` — преобразование компактного ответа JSON.
- `uplink.js` — DNS через собственный файл Internet Uplink приложения.
- `package.json` — метаданные исходного проекта; при сборке пакетный файл создаёт `kit/tools/build.py`.

[Документация iDrive7 apps](https://github.com/cauliflowermossgrape/idrive7-apps) описывает виджеты и сборку. [MGU Store](https://github.com/robertnisipeanu/mgu-store) описывает установку исходников и Internet Uplink.
