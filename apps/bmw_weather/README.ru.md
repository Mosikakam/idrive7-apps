# BMW Weather — пользовательский виджет для MGU / iDrive 7

Пакет содержит исходники приложения, экран прогноза и виджет главного экрана BMW. Данные запрашиваются напрямую из Open-Meteo через HTTPS; BMW Online и ConnectedDrive не используются.

## Что включено

- текущая температура, ощущаемая температура, влажность, ветер и описание погоды;
- анимированные солнце, облака, дождь и снег;
- прогноз на пять дней с максимумом/минимумом и вероятностью осадков;
- обновление по умолчанию каждые 30 минут и кнопка ручного обновления;
- виджет `startWidget` на шаблоне BMW `LT_Table_OnlineApps_DriveRecorderWidget`;
- запрос только при работающем процессе; при сетевой ошибке в текущем сеансе остаётся последнее успешно полученное значение.

Источник данных: [Open-Meteo Forecast API](https://open-meteo.com/en/docs). На экране есть атрибуция. Бесплатный endpoint разрешён для личного некоммерческого использования; коммерческое использование требует платного плана. Условия и лицензия данных могут меняться — см. [условия Open-Meteo](https://open-meteo.com/en/terms).

## Место прогноза

Установлены примерные координаты центра Петропавловска-Камчатского: `53.017, 158.650`. Это не координаты автомобиля или дома. MGU не предоставляет приложению подтверждённый здесь API геолокации автомобиля.

Чтобы выбрать другое место, измените `LOCATION_LATITUDE` и `LOCATION_LONGITUDE` в начале `weather.js` перед сборкой. Приложение отправляет эти координаты в Open-Meteo при каждом запросе погоды.

## Сборка и установка через MGU Store

Исходники готовы для сборки MGU Store на головном устройстве. Готовый `.tgz` или `.mgu` без BMW `oap-sdk` с конкретного устройства получить нельзя; SDK не распространяется в репозитории. MGU Store извлекает его из штатного приложения на самом устройстве. Подпись пакета для этого способа установки не требуется.

1. Сделайте собственную копию (fork) [idrive7-apps](https://github.com/cauliflowermossgrape/idrive7-apps). Это исходный комплект, содержащий сборщик, renderer и `mgu-repo.json` для MGU Store.
2. Скопируйте эту папку `bmw-weather-widget` в комплект как `apps/bmw_weather/`.
3. В `apps/bmw_weather/weather.js` задайте координаты, затем зафиксируйте изменения в своей копии GitHub.
4. Каталог комплекта объявляет для приложений `mguHmi: ["ID7"]`. `app.json` содержит `mguInternet: true`, и `kit/tools/build.py` переносит этот флаг в `package.json` готового пакета. `package.json` рядом с исходниками сам по себе сборщиком не используется.
5. В MGU Store добавьте `Mosikakam/idrive7-apps` как источник ветки `main` или обновите уже добавленный источник через Settings → Check now. Каталог этого форка предлагает только **Weather**. Выберите приложение и установите его. Store соберёт `.tgz` на MGU с локальным SDK; если предложит перезапуск — выполните его.
6. На головном экране откройте выбор виджетов и добавьте **Weather**. Наличие приложения в списке виджетов, точный размер и кадрирование картинки нужно подтвердить на машине.
7. Откройте приложение и проверьте обновление вручную. Убедитесь, что MGU Store показывает Internet Uplink как `Online`.

Не устанавливайте пакет, если Store сообщает о несовместимом HMI, отсутствующем SDK или невыданном интернет-разрешении. В таком случае сохраните журнал ошибки и остановитесь до разбирательства.

## Если после установки виджет пустой

Обновите Weather до версии 1.0.3 в MGU Store. Эта версия запускает получение погоды и отрисовку также при запуске приложения только домашним виджетом. В текстовой части плитки должен появиться статус Weather даже до получения изображения. Если плитка остаётся пустой, сохраните журнал приложения из Store: это поможет отличить ошибку запуска виджета от ошибки передачи картинки в HMI.

Версия 1.0.2 также исправляет запрос HTTPS для Node.js 8 на MGU: предыдущая версия показывала `"listener" argument must be a function` до подключения к Open-Meteo. Версия 1.0.3 устраняет `EAI_AGAIN` из-за системного DNS MGU: Weather берёт DNS-серверы из собственного файла подключения Internet Uplink. Если вместо прогноза появится `No Internet Uplink lease for Weather`, проверьте статус Uplink в Store. При `Offline` подключите Uplink к сети; при `Online` переустановите Weather через Store, чтобы deploy tool заново зарегистрировал приложение для интернет-доступа. Если после переустановки ошибка остаётся, нужно проверить на MGU установленный `source/package.json` (`mguInternet: true`), файл `/var/opt/mgu-uplink/apps.d/bmw_weather` и наличие `data/uplink.json` у Weather; экран Store сам по себе не показывает регистрацию приложения. Затем вновь добавьте плитку Weather, если Store удалит её при переустановке. Если после обновления появится другая ошибка, сохраните её текст.

При сообщении `Weather unavailable` откройте Weather: под ним теперь отображается конкретная причина сетевой ошибки (например, код DNS или TLS). Запишите её дословно и проверьте, что Internet Uplink в MGU Store показывает `Online`. Отсутствие прогноза на экране и пустая домашняя плитка могут иметь разные причины.

## Совместимость и неподтверждённые части

| Возможность | Статус |
|---|---|
| MGU / iDrive 7 как целевая платформа | Заявлено в манифесте как `ID7`; исходный комплект ориентирован на MGU. |
| BMW X3 G01 с MGU High | Архитектурно ожидаемо, но на конкретном автомобиле не проверено. |
| `P18_23w44.2-1-3` | Не подтверждено на этой точной версии. Публичный комплект сообщает о разработке/проверках на `P18_23w44.2`; это не доказывает совпадение локального шаблона виджета или SDK для суффиксной версии. |
| `startWidget` и шаблон `LT_Table_OnlineApps_DriveRecorderWidget` | API/структура подтверждены документацией комплекта; сам шаблон и crop для этого G01 нужно проверить на автомобиле. |
| Интернет через MGU Internet Uplink | Store документирует подключение сторонних приложений; для приложения выставлен флаг `mguInternet`. DNS, TLS-сертификаты, маршрут и доступ к `api.open-meteo.com` именно на вашей установке не проверены. |
| Анимация | Реализована через циклическую перерисовку Canvas; частота ограничена 2 кадрами/с в виджете. Работа/плавность на данном блоке не измерялась. |
| Готовый `.mgu` | Не сформирован: необходим SDK-донор с вашего автомобиля. Store собирает устанавливаемый `.tgz` непосредственно на MGU. |

## Границы изменений

Приложение делает обычные HTTPS-запросы к Open-Meteo и не вызывает API BMW Online/ConnectedDrive, не меняет аккаунты BMW и не перенаправляет штатный сетевой трафик. Сам MGU Store использует поддерживаемый комплектом механизм установки пользовательских приложений на MGU; этот механизм добавляет приложение на локальную головную систему. Перед установкой проверьте собственную политику и резервное копирование для уже модифицированной системы.

## Структура

- `app.json` — экран, настройки и описание `startWidget`.
- `package.json` — метаданные MGU Store, совместимость ID7 и интернет-разрешение.
- `main.js` — запуск экрана и домашнего виджета.
- `weather.js` — Open-Meteo клиент, погодная логика, Canvas-графика и анимация.
- `uplink.js` — разрешение имени через DNS-серверы из файла подключения Internet Uplink для Weather.
- `icon.png` — значок приложения для списка MGU Store и меню BMW.
